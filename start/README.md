# Loja Recife (start)

App Angular do workshop de acessibilidade. Esta versão contém problemas de acessibilidade **intencionais**: investigue, registre e corrija.

```bash
npm install
npm start      # http://localhost:4200
```

Arquivos que importam: `src/app/app.ts`, `src/app/app.html`, `src/app/app.css`.
