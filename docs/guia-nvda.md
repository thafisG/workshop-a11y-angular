# Guia básico de NVDA para o workshop

NVDA é um leitor de tela gratuito para Windows. Ele lê em voz alta o que está na tela e o que está em foco.
Neste workshop você só precisa de uns poucos comandos.

## Antes de tudo

- **Instalar:** <https://www.nvaccess.org/download/>
- **Iniciar:** `Ctrl + Alt + N` (atalho padrão da instalação) ou pelo menu Iniciar.
- **Tecla NVDA:** por padrão é `Insert` (ou `Caps Lock`, se você ativou). Abaixo, `NVDA` = essa tecla.
- **Parar de falar na hora:** `Ctrl`.
- **Encerrar o NVDA:** `NVDA + Q`.
- **Voz em português:** `NVDA + Ctrl + V` abre as configurações de voz. Escolha um sintetizador/voz pt-BR e **reduza a velocidade** se estiver difícil acompanhar.
- **Dica para projetar:** menu do NVDA (`NVDA + N`) → Ferramentas → **Visualizador de fala**. Mostra em texto tudo que o NVDA fala. Ótimo para registrar descobertas no FigJam e para quem está ao lado.

## Os comandos do workshop

| Quero… | Faça |
|---|---|
| Ir para o próximo/anterior item focável | `Tab` / `Shift + Tab` |
| Ativar botão ou link | `Enter` (links e botões) ou `Espaço` (botões) |
| Fechar diálogo | `Esc` |
| Ler linha a linha | `↓` / `↑` (modo de navegação) |
| Ler tudo a partir daqui | `NVDA + ↓` |
| Ouvir de novo onde está o foco | `NVDA + Tab` |
| Pular de título em título | `H` / `Shift + H` |
| Pular de botão em botão | `B` / `Shift + B` |
| Pular de campo de formulário em campo | `F` / `Shift + F` |
| Pular de imagem em imagem | `G` / `Shift + G` |
| Pular entre regiões da página | `D` / `Shift + D` |
| Ver lista de títulos, links, botões, campos | `NVDA + F7` |
| Alternar modo de navegação ↔ modo de foco | `NVDA + Espaço` |

## Modo de navegação x modo de foco (a única ideia difícil)

- **Modo de navegação:** você "passeia" pela página com setas e letras (`H`, `B`, `F`). Foi feito para ler.
- **Modo de foco:** as teclas vão direto para o campo (você digita). O NVDA troca sozinho ao entrar em campos de texto; você ouve um sonzinho.
- Se digitar `h` e ele pular de título em vez de escrever no campo, você está em modo de navegação: aperte `NVDA + Espaço`.

## Roteiro de exploração (10 minutos)

Faça cada passo duas vezes: **(1)** só com teclado, sem NVDA (`Tab`, `Enter`); **(2)** com NVDA e, se quiser, de olhos fechados ou com a tela desligada.

1. Carregue a página. O que o NVDA anuncia primeiro?
2. `D` e `H`: a estrutura da página faz sentido?
3. `G`: o que ele diz de cada imagem?
4. `B`: o que ele diz de cada botão? Você sabe o que cada um faz?
5. Adicione um produto ao carrinho. Alguém avisou que deu certo?
6. Abra o carrinho. Para onde foi o foco? Aperte `Tab` várias vezes: onde você vai parar? `Esc` fecha?
7. Tente preencher o formulário com `F`. O que o NVDA diz de cada campo?
8. Envie o formulário vazio. Você descobre o que errou? Depois envie preenchido.
9. Tente favoritar um produto só com o teclado.

Anote cada descoberta com: **o que eu esperava / o que aconteceu / por que atrapalha**.

## Se o NVDA não falar

- Confira o volume e se a voz está instalada (`NVDA + Ctrl + V`).
- Reinicie o NVDA (`NVDA + Q`, abra de novo).
- Com o Chrome já aberto antes do NVDA, recarregue a página (`F5`).
- Se nada funcionar, acompanhe a demonstração na máquina do facilitador.
